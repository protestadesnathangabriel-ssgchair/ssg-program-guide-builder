# Core editor acceptance tests

- [ ] Google sign-in succeeds for each of the three approved accounts.
- [ ] An unapproved account is signed out and cannot read Firestore documents.
- [ ] Create Program Flow and Program Sequence guides.
- [ ] Edit title, date, venue, call time, formal start, BGM and reference link.
- [ ] Add/remove sections and add/remove items; edit all item fields.
- [ ] Wait for autosave status; refresh and verify all nested fields remain.
- [ ] Open Display in a second window; edit guide and confirm live changes appear.
- [ ] Open same guide on a second device and verify cross-device draft updates.
- [ ] Operator cannot delete guides; admins can delete test guides.
- [ ] Export JSON and verify it contains the nested guide data.
- [ ] Verify layout on desktop, tablet-width and mobile-width screens.

Do not migrate production guides until every applicable test passes.
